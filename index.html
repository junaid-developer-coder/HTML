Quick start

Three steps from clone to a running page.

  1. Clone the repository

    Grab the code and move into the project folder.

    git clone https://github.com/you/project-name.git
cd project-name

  2. Serve it locally

    Any static server works — here's a dependency-free option.

    npx serve .
# or: python3 -m http.server 8000

  3. Make it yours

    Edit the content in index.html, adjust tokens in assets/css/style.css, and update the README.
